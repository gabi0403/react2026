# Casa Nativa

Loja virtual desenvolvida com React e Vite para praticar componentes, props, eventos e estado.

## Requisitos

- Node.js instalado
- npm instalado

## Instalação

No terminal, acesse a pasta do projeto e instale as dependências:

```bash
cd react2026/exercicio-semana1/loja-virtual
npm install
```

## Execução

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

Depois, abra o endereço exibido pelo Vite no navegador.

## Outros comandos

```bash
npm run build
npm run lint
npm run preview
```
